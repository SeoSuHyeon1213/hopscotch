# 자연과 인간의 땅따먹기 (Nature vs. Human)

## 1. 작품주제

### 지배와 잠식 — 인간 개입이 부르는 두 가지 재앙

인간이 개입하면 자연이 파괴되고, 인간이 손을 떼면 자연이 인간 문명을 잠식한다.  
이 작품은 **'공존'이 얼마나 어려운 균형인지**를 관람객이 직접 버튼을 조작하며 체험하게 합니다.

> "인간이 개입하면 자연이 파괴되고, 인간이 방치하면 자연이 모든 것을 잠식한다. 어느 쪽도 공존이 아니다."

- **인간 개입 (버튼 조작) → 자연 파괴**
  - 건물·도로가 녹지를 덮음
  - 동물이 사라짐
- **인간 방치 (버튼 무조작) → 자연의 역습**
  - 덩굴·이끼가 문명을 잠식
  - 건물이 무너짐
- **어떤 선택도 평화롭지 않다**
  - 균형의 순간을 찾는 것이 이 작품의 질문

---

## 2. 작품컨셉

🔴 **빨간 버튼을 누르면 인간이 자연을 파괴하고, 손을 떼면 자연이 인간 문명을 서서히 잠식하는 인터랙티브 미디어 아트 설치 작품**

### 핵심 작동 개념

| 구분 | 작동 |
|---|---|
| 🏗 인간 개입 | 버튼 누름 → 건물·도로 확산 → 나무·동물 소멸 → 자연 파괴 |
| 🌿 인간 방치 | 버튼 무조작 → 덩굴·이끼·식물 확산 → 건물 침식 → 문명 잠식 |

### 빨간 버튼의 이중 의미

| 의미 | 설명 |
|---|---|
| 유혹 (Temptation) | 누르고 싶게 만드는 원색의 자극 — 아케이드 감성, 즉각적인 반응 욕구 |
| 파괴 (Destruction) | 누르는 행위 = 자연을 직접 파괴하는 상징적 행동 |
| 경고 (Warning) | 손을 떼는 순간 자연의 역습이 시작된다는 긴장감 |

### 역설적 구조 — 어느 선택도 평화롭지 않다

- 버튼을 누르면 → 자연이 파괴됨  
  - 인간이 이기는 것처럼 보이지만 자연은 사라짐
- 버튼을 놓으면 → 자연이 역습하여 인간 문명을 잠식함
- 관람객은 **'개입'과 '방치' 사이에서 불안**을 체험하며 진정한 공존이 무엇인지 스스로 질문하게 됨

## 3. 작품방향

인간의 개입은 자연을 파괴하고, 인간의 방치는 자연의 역습을 부른다는 메시지를 체험으로 전달합니다.  
관람객이 직접 선택하고, 결과를 목격하며, 스스로 질문에 도달하는 구조입니다.

### 관람객 경험 흐름

| 단계 | 관람객 행동 | 화면 변화 | 의도된 감정 |
|---|---|---|---|
| 진입 | 빨간 버튼 발견 | 자연 가득한 초기 화면 | 호기심, 유혹 |
| 개입 | 버튼 눌러 도시 확산 확인 | 건물 확장, 나무·동물 소멸 (자연 파괴) | 성취감, 가벼운 죄책감 |
| 방치 | 버튼에서 손을 뗌 | 덩굴·이끼가 건물 잠식 (자연 역습) | 놀람, 불안, 위협감 |
| 반복 | 개입 ↔ 방치 반복 | 두 세계가 끊임없이 충돌 | 긴장, 피로, 성찰 |
| 깨달음 | 어느 쪽도 평화롭지 않음을 인식 | 경계선이 요동침 | 공존의 의미 체감 |

### 시각적 방향

| 상태 | 시각 특성 | 사운드 |
|---|---|---|
| 인간 개입 중 | 회색 건물·도로 확산 / 픽셀 글리치 / 녹지 소멸 | 파쇄음, 드릴 소리, 기계음 |
| 인간 방치 중 | 덩굴·이끼·나무 확산 / 건물 균열·붕괴 연출 | 바람, 벌레 소리, 식물 자라는 소리 |
| 경계 충돌 | 파티클 이펙트 — 두 세계가 뒤섞임 | 두 사운드가 혼합되며 어느 쪽이 지배하는지 변화 |

| 인터랙션 방식 | 아두이노 연결 아케이드 버튼 조작 |

### 핵심 메커니즘

| 상태 | 조건 | 자연 반응 | 인간 문명 반응 |
|---|---|---|---|
| 인간 개입 | 버튼 TAP / HOLD | 나무·동물 소멸, 녹지 파괴 | 건물·도로 확산, 회색 영역 증가 |
| 인간 방치 | 버튼 IDLE (2초+) | 덩굴·이끼·식물 확산, 역습 시작 | 건물 침식·붕괴, 회색 영역 잠식 |

### 인터랙션 구조 — 버튼 입력 3단계

| 입력 상태 | 조건 | 효과 |
|---|---|---|
| TAP | 0.5초 내 짧게 누르고 뗌 | 건물 소폭 확산 → 자연 소폭 파괴 |
| HOLD | 1초 이상 길게 누르고 있음 | 건물 빠르게 확산 → 자연 급속 파괴 |
| IDLE | 2초 이상 무입력 방치 | 자연 역습 시작 → 덩굴·이끼가 건물·도로를 잠식 |

### 두 영역의 대립 로직

| 구분 | 자연 (Nature) | 인간 (Human) |
|---|---|---|
| 활성 조건 | IDLE 2초+ → 자연 역습 (잠식 시작) | TAP/HOLD → 자연 파괴 (확산 시작) |
| 확산 알고리즘 | Perlin Noise 유기적 확산 (덩굴, 이끼) | 랜덤 그리드 스탬프 (건물, 도로) |
| 시각적 질감 | 곡선·녹색·이끼·덩굴 — 건물에 침투 | 직선·회색조·건물 — 녹지 파괴 |
| 사운드 | 바람, 숲 앰비언트, 식물 자라는 소리 | 파쇄음, 기계음, 드릴 소리 |
| LED 연출 | 자연 잠식도 높을수록 서서히 꺼져감 | 빠른 점멸 / 강한 점등 |
